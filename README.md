# CloudFlow - SaaS服务落地页

这是一个现代化的SaaS服务落地页演示项目。

## 功能特性

- 📱 响应式设计，完美支持桌面和移动设备
- 🎨 现代化渐变色设计和卡片式布局
- ⚡ 平滑滚动导航和动画效果
- 🔧 纯HTML/CSS/JavaScript实现，无需外部依赖

## 页面内容

- **导航栏**：品牌标识和主要导航链接
- **Hero区域**：核心价值主张和关键统计数据
- **功能展示**：6个核心功能介绍
- **价格方案**：3个灵活的定价选项
- **客户评价**：真实用户推荐
- **行动号召**：免费试用引导
- **页脚**：详细的产品和公司信息

## 快速开始

1. 克隆仓库：
```bash
git clone https://github.com/duzi202601/demo.git
cd demo
```

2. 使用本地服务器打开：
```bash
# 使用Python
python -m http.server 8080

# 或使用Python 3
python3 -m http.server 8080
```

3. 在浏览器中访问：`http://localhost:8080/index.html`
