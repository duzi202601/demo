# AI Bot 会话功能

这是一个简单的 AI Bot 与网页访问者的会话功能演示。

## 功能特点

- 🤖 **AI 智能对话**：支持与 AI Bot 进行实时会话
- 💬 **流畅的聊天体验**：包含正在输入提示动画和消息滚动
- 📱 **响应式设计**：适配桌面和移动设备
- ⌨️ **键盘支持**：按 Enter 键即可发送消息
- ⏰ **时间戳显示**：每条消息都显示发送时间

## 文件结构

```
demo/
├── index.html    # 主页面
├── styles.css    # 样式文件
├── chat.js       # 会话功能脚本
└── README.md     # 说明文档
```

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 在输入框中输入消息
3. 点击"发送"按钮或按 Enter 键发送消息
4. AI Bot 将自动回复您的消息

## 支持的对话类型

- **问候语**：你好、您好、Hi、Hello 等
- **帮助请求**：帮助、怎么用、如何、功能 等
- **感谢**：谢谢、感谢、多谢 等
- **告别**：再见、拜拜、下次见 等

## 技术栈

- HTML5
- CSS3 (Flexbox, Animations, Gradients)
- JavaScript (ES6+)
