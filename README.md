# Demo - 白天/黑夜切换效果

这是一个演示白天/黑夜自动切换效果的网页应用。

## 功能特点

- **时间自动切换**: 页面会根据当前系统时间自动切换主题
  - 白天模式 (6:00 - 18:00): 明亮的蓝天背景，带有浮动云朵效果
  - 夜晚模式 (18:00 - 6:00): 深色星空背景，带有闪烁星星效果
- **实时时钟**: 显示当前时间
- **平滑过渡**: 主题切换时带有平滑的过渡动画效果

## 使用方法

直接在浏览器中打开 `index.html` 文件即可查看效果。

## 技术实现

- 纯 HTML/CSS/JavaScript 实现，无需任何依赖
- 使用 CSS 渐变和动画实现视觉效果
- 使用 JavaScript 定时器实现时间更新和主题切换
