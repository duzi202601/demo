# CloudFlow - 智能SaaS服务平台

一个现代化的 SaaS 落地页，采用统一协调的设计系统。

## 特性

- 🎨 **统一设计系统** - 一致的颜色、间距、字体和动画
- 📱 **响应式设计** - 完美适配桌面、平板和移动设备
- ⚡ **流畅动画** - 平滑的滚动动画和交互效果
- ♿ **可访问性** - 支持键盘导航和屏幕阅读器

## 文件结构

```
├── index.html    # 主页面结构
├── styles.css    # 统一设计系统样式
├── script.js     # 交互逻辑
└── README.md     # 项目说明
```

## 设计规范

### 颜色系统
- 主色调: `#6366f1` (靛蓝色)
- 渐变: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`

### 间距系统
采用 4px 基础单位的倍数，确保视觉一致性。

### 字体系统
- 中文优先: PingFang SC, Hiragino Sans GB, Microsoft YaHei
- 西文: -apple-system, BlinkMacSystemFont, Segoe UI

## 使用方法

直接在浏览器中打开 `index.html` 文件即可预览。
