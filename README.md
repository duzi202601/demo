# Demo - Modern UI

A sleek, modern UI demo featuring a clean and cool design.

## ✨ Features

- 🎨 **Modern Design** - Glassmorphism effects with gradient colors
- 🌙 **Dark Theme** - Carefully tuned dark color scheme to reduce eye strain
- 📱 **Responsive Layout** - Perfect adaptation across all screen sizes
- ⚡ **Smooth Animations** - Fluid transitions and interactive effects
- 🔧 **Pure Native Implementation** - No framework dependencies

## 🚀 Quick Start

Simply open `index.html` in your browser to view the demo.

```bash
# Or use a local server (VS Code Live Server, Python, etc.)
python -m http.server 8000
```

Then visit `http://localhost:8000`

## 📁 Project Structure

```
demo/
├── index.html    # Main page (HTML, CSS, JS)
└── README.md     # Project documentation
```

## 🎯 Design Philosophy

- **Simple but not simplistic** - Remove redundant elements, keep core features
- **Clear visual hierarchy** - Establish information levels through color, size, and spacing
- **Instant interaction feedback** - Every action has corresponding visual feedback
- **Details define quality** - Every detail is polished, from scrollbars to animations
